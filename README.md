Leave Application System is a web-based application developed using ASP.NET Web Forms and C#. It allows employees to select a leave date, enter their details, choose a leave type, provide a reason, and submit a leave application. The project demonstrates the use of ASP.NET Rich Controls, Session State, and Cookies.

Features
  📅 Interactive calendar for selecting the leave date
  👤 Employee name entry
  📝 Leave application form
  🏥 Multiple leave types:
    -Personal Leave
    -Medical Leave
    -Emergency Leave
  💬 Reason for leave
  🍪 Cookie-based Remember my name functionality
  🔐 Session-based storage of leave details
  ✅ Displays a successful submission message with employee name, date, leave type, and reason
  
Technologies Used
  C#
  ASP.NET Web Forms
  HTML
  ASP.NET Calendar Control
  Session Management
  Cookies
  
Project Workflow
  -User selects a leave date from the calendar.
  -The selected date is stored in the session.
  -User clicks Apply Leave to open the leave application form.
  -Employee enters their name and selects a leave type.
  -User provides the reason for leave.
  -If Remember my name is selected, the employee name is stored in a cookie for 7 days.
  -The application displays the submitted leave details with a success message.
